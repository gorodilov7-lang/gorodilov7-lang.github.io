Настоящая Политика конфиденциальности действует в отношении всей информации, которую самозанятый мастер [ФИО], ИНН [номер] (далее — «Оператор»), может получить о Пользователе во время использования сайта https://tihaya-pava.netlify.app (далее — «Сайт»).

2. Какие данные собираются

Оператор может собирать следующие категории персональных данных:

  • Имя — для персонализации обращения;
  • Контактные данные (Telegram, номер телефона) — для связи по заказу;
  • Город доставки — для расчёта стоимости и логистики;
  • Описание желаемого изделия — для выполнения заказа;
  • Техническая информация, автоматически передаваемая браузером (IP-адрес, тип устройства, cookies) — для функционирования Сайта.

Специальные категории данных не обрабатываются. Оператор не собирает данные о расовой принадлежности, политических взглядах, религиозных или философских убеждениях, состоянии здоровья.

3. Цели обработки данных

Персональные данные обрабатываются исключительно в следующих целях:

  • Связь с Пользователем по оставленной заявке;
  • Обсуждение деталей индивидуального заказа (макраме, вышивка);
  • Расчёт стоимости доставки;
  • Исполнение договора на изготовление изделия;
  • Улучшение работы Сайта (обезличенная статистика).

4. Правовые основания

Обработка осуществляется на основании:

  • Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных»;
  • Согласия Пользователя на обработку персональных данных (предоставляется путём проставления отметки в форме заявки / нажатия кнопки «Отправить»);
  • Гражданского кодекса РФ (исполнение договора).

5. Порядок обработки и хранения

  • Данные хранятся в зашифрованном виде на серверах Netlify (ЕС/США) и в мессенджерах (Telegram/WhatsApp) на устройстве Оператора.

  • После истечения срока данные удаляются без возможности восстановления.
  • Оператор не передаёт данные третьим лицам, за исключением случаев, прямо предусмотренных законодательством РФ (запрос суда, правоохранительных органов).

  • Отозвать согласие на обработку — направив запрос на контактный адрес (см. раздел 8).

Внимание: отзыв согласия делает невозможным выполнение текущего заказа, если данные необходимы для его исполнения.
